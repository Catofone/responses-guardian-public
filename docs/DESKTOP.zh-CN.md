# Guardian 桌面管理器

双击 `Guardian.exe` 启动或连接本机代理，先开启 CCSwitch 本地代理。关闭管理窗口保留后台代理；只有点击“停止代理”才执行原有的安全检查和路由恢复。

## 1.6.3 窗口与布局

窗口使用 Windows 原生标题栏、可缩放边框、阴影及最小化/恢复动画，没有独立的透明阴影窗口，也不反复设置窗口裁剪区域。支持从四边及四角调整尺寸、最大化、最小化和恢复。最小尺寸为 800 × 540（100% 缩放）；控件高度与间距随可用空间连续调整，正常工作台和设置页无需滚动，主要操作按钮固定在底部。额外错误详情过长时仍可滚动查看。Windows 10/11 按各自的系统外观显示窗口边界。

布局不在固定宽高处切换整套尺寸或隐藏设置说明。连接和重试分组的说明分别保留在对应输入列下方；输入框、文件选择和重试控件的边界完整可见。左侧圆环是独立的背景元素，只按背景面板的宽高定位和缩放，角色图片的比例和大小不参与计算；圆环与问候文字、底部提示框保持距离。个人皮肤文件保持独立，布局调整不修改图片像素。

1.6.1 从 Windows 窗口读取实际 DPI，避免 .NET 兼容模式报告 96 DPI、而绘制使用 120 DPI 时出现的裁切。连接线路卡片为底部地址保留足够高度；三个节点的文字分别限制在各自列内，过长地址显示省略号。

1.6.2 在布局完成后使用页面的实际可用高度核对内容，必要时缩减分组间的留白和顶部间距，文字、输入框和卡片保持完整高度。这样可以容纳不同系统边框及 DPI 取整造成的几像素差异。连续缩放时，滚动范围在间距调整完成后统一更新。额外错误或重启提示导致内容确实放不下时，仍可滚动查看全部内容；恢复正常页面后清除多余滚动条及旧滚动位置。

缩放时减少嵌套容器的重复自动排版，合并间距与行高更新，并暂缓新的定时状态刷新。个人图片预先生成预览缓存，拖动边框时使用轻量缩放；松开边框后恢复当前尺寸的高质量图像缓存，后续重绘复用缓存。窗口大小和图片位置仍连续变化，预览不会改写皮肤源文件。

重复打开管理器会聚焦已有窗口；只有原窗口最小化时才执行恢复，不会把已最大化的窗口强制改回普通尺寸。

## 设置与编辑历史

首次运行默认 off，以后沿用保存的模式。模式切换影响后续请求，无需重新启动管理器或 Codex。

连接成功后，“连接代理”按钮显示为灰色“已连接”并禁用；工作台的“刷新”仍然可用。连接失败或代理停止后，连接按钮恢复可用。

模式切换时，模式区域显示“正在切换…”，刷新、停止等未参与操作的按钮保留原有外观。后台定时刷新也保留按钮外观，状态没有变化时减少重绘。操作执行期间仍临时禁用交互，重复点击不会执行或排队；成功及失败都会解除锁定。连接、手动刷新、保存和停止操作继续显示各自的执行状态；真正不可用的按钮仍置灰。

重试次数通过“− / 数值 / +”控件、直接输入或上下方向键调整，范围为 0–100。数值无效时保留草稿并暂时禁用保存。

保存状态比较当前草稿与已保存值。改回原值会恢复“设置已保存”；文本两端空格和数字前导零按实际保存语义处理。Ctrl+Z 撤销，Ctrl+Y / Ctrl+Shift+Z 重做，也可使用设置页按钮。窗口内保留最近 100 步编辑。撤销只修改草稿，需要再次点击保存才会修改磁盘配置。

定时刷新不会清空未保存的草稿或相同设置的历史。保存期间继续输入的内容也会保留。地址、提供商或配置文件变更按现有代理流程在重新启动后应用；重试次数在 Codex 重启后读取。

## 个人皮肤与公开版本

所有构建使用相同的公开程序，不把个人图片嵌入 EXE。普通启动时，可从本机 `%LOCALAPPDATA%\ResponsesGuardian\skins\companion.png` 加载可选 PNG；无图片或加载失败时使用原创默认小助手。图片只在本机读取，不上传、不调用模型、不访问远程素材。

需要以默认外观截图时使用 `Guardian.exe --public-preview`；该模式强制使用默认图案，使用独立的窗口实例标识，不会切换到已经打开的个人皮肤窗口。

公开发行请执行：

```powershell
.\scripts\package-public.ps1 -OutputDirectory .\artifacts\release
```

打包脚本从源码重新构建程序，按白名单复制源码和素材，检查 EXE 内嵌资源及包内文件，再生成 ZIP。配置、日志、备份和外部皮肤由各使用环境单独管理，不随发行包提供。

## 构建与验证

需要 Windows 10/11 x64、.NET Framework 4.8、Windows PowerShell 5.1；构建代理还需 Go 1.25+。桌面部分不依赖额外 GUI 库。源码和默认图标采用 MIT，第三方许可见 `licenses/` 与 `THIRD-PARTY-NOTICES.md`。

```powershell
.\scripts\build-desktop.ps1
go test -count=1 -run TestWindowsDesktopManagerUI -v ./cmd/responses-guardian
```

测试使用临时配置、临时端口和模拟上游，覆盖原生缩放边缘、连续缩放与松开后的布局一致性、跨临界尺寸逐像素缩放时的位置变化、宽矮窗口圆环范围、输入控件裁切、连接按钮状态、反复最小化与恢复、窗口句柄和草稿保持、重启提示的展开与收起、默认皮肤、公开 EXE 资源、编辑历史、配置验证、模式切换、离线修复和保护性停止。额外在 96、120、144、192 DPI 下回放整页布局，包含报告的 978 × 616 客户区、较小客户区、放大后缩回、双页切换和错误详情出现/消失；同时检查连接线路绘制、文字边界及圆环独立性。这些布局和位图检查不替代真实多显示器环境验证。UI 线程未处理异常会使测试失败。测试不会停止正在运行的正式代理。

按钮闪动回归逐像素比较操作前、临时锁定中及完成后的按钮图像，并尝试点击以验证输入拦截。覆盖在线模式切换、后台刷新、切换失败、错误后的自动刷新，以及较慢的离线模式保存。
